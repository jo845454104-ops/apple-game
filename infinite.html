📖 점수 계산법

획득 점수 = ( 사과 점수 + 묶음 보너스 + 황금 보너스 ) × 콤보 배율

사과 점수
한 번에 터뜨린 사과 1개당 10점.
2개 = 20점 · 3개 = 30점 · 5개 = 50점
묶음 보너스
4개 이상을 한 번에 묶으면 4번째부터 1개당 +30점.
4개 = +30 · 5개 = +60 · 6개 = +90
✨ 황금 보너스
황금 사과 1개당 +100점.
콤보 배율 (점수의 핵심)
콤보 1당 +0.2배, 콤보 45에서 ×10로 상한.
콤보 1 = ×1.2 · 콤보 10 = ×3.0 · 콤보 45↑ = ×10
콤보 쌓는 법
직전에 터뜨린 뒤 2.5초 안에 다시 터뜨려야 콤보가 이어집니다. 뜸을 들이면 성공해도 콤보가 1로 초기화됩니다.
제한시간 (점점 짧아짐)
첫 판만 8초를 주고, 이후로는 6초에서 시작해 버틴 시간 30초마다 0.1초씩 줄어 4.5초에서 멈춥니다.
0~30초 = 6.0초 · 2분 30초 = 5.5초 · 7분 30초↑ = 4.5초
게임 종료
제한시간 안에 하나도 못 터뜨리면 종료. 터뜨릴 때마다 시간이 다시 채워집니다.

예) 콤보 10에서 황금 1개 포함 5개를 묶으면
( 50 + 60 + 100 ) × 3.0 = 630점
